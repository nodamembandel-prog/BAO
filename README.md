# Bio Accoustic OS (BAO)

Aplikasi prototipe untuk memancarkan frekuensi audio guna memanipulasi materi (Bio-Regen, Hydro-Repel, Purify).

## Pembaruan (v3):
- Logo diperbarui menjadi desain murni warna putih (solid white).
- Font (jenis huruf) diubah menjadi lebih tebal dan tegas (menggunakan 'Impact' atau 'Arial Black').

## Isi Paket Ini:
1. `index.html` - Antarmuka aplikasi, logika kontrol suara, dan panel About.
2. `logo.svg` - Logo resmi BAO untuk aplikasi.
3. `manifest.json` - File konfigurasi agar web ini bisa diinstal sebagai aplikasi Android asli.
4. `README.md` - Petunjuk penggunaan.

## Cara Mengubah Menjadi Aplikasi (APK / Terinstal di Android):

Telah ditambahkan fitur **PWA (Progressive Web App)** di paket ini. Artinya Anda bisa menginstalnya langsung di HP tanpa perlu repot convert ke APK!

**Langkah-langkah di GitHub:**
1. Ekstrak file zip ini.
2. Upload semua file (`index.html`, `logo.svg`, `manifest.json`) ke repository GitHub baru Anda.
3. Aktifkan **GitHub Pages** di menu Settings > Pages.

**Langkah Instalasi di Android Anda:**
1. Buka link GitHub Pages Anda melalui browser **Google Chrome** di Android.
2. Saat web terbuka, Chrome biasanya akan memunculkan *pop-up* di bawah layar: **"Add BAO to Home screen"**.
3. Jika *pop-up* tidak muncul, ketuk ikon titik tiga (opsi) di sudut kanan atas Chrome, lalu pilih **"Install app"** atau **"Add to Home screen"**.
4. Aplikasi "BAO" akan terinstal beserta logonya di laci aplikasi (app drawer) Android Anda. Saat dibuka, tampilannya akan persis seperti aplikasi APK mandiri (tanpa bingkai browser)!
